Модель: GPT-6.1 Sol

## О работе

Созданы две версии мини-трекера учебных задач:

- tracker-v1.html — по короткому прямому запросу;
- tracker-v2.html — после подготовки спецификации.

Во второй попытке использована спецификация в формате OpenSpec,
без запуска OpenSpec CLI.

## Как запустить

1. Скачать файлы репозитория через Code → Download ZIP.
2. Распаковать архив.
3. Открыть tracker-v1.html из папки attempt-1-direct
   или tracker-v2.html из папки attempt-2-spec в браузере.

Установка библиотек и запуск сервера не требуются.

## Где что находится

- attempt-1-direct/tracker-v1.html — первая версия.
- attempt-1-direct/report.md — общий отчёт по обеим версиям.
- attempt-2-spec/tracker-v2.html — вторая версия.
- attempt-2-spec/proposal.md — цель и границы.
- attempt-2-spec/specs/tracker/spec.md — требования и сценарии.
- attempt-2-spec/design.md — устройство данных и расчётов.
- attempt-2-spec/tasks.md — план реализации и проверок.
- prompts.txt — запросы к модели.
- screenshots/ — скриншоты приложений.

## Проверки

Обе версии проверены вручную по сценариям T1–T5:
исходные показатели, переключение готовности,
фильтрация, валидация и пустое состояние.

Результаты проверок и ограничения сравнения приведены
в attempt-1-direct/report.md.

Скриншоты интерфейса находятся в папке screenshots/.
