# Изменение: автономный мини-трекер учебных задач

## Цель

Подготовить автономный мини-трекер учебных задач на неделю: один файл
`tracker-v2.html` со встроенными CSS и JavaScript.

Пользователь может добавлять и удалять задачи, переключать их готовность,
фильтровать список и видеть суммарные часы и прогресс выполнения.

## Границы

В обязательный объём входят:
- модель задачи: `id`, `title`, `hours`, `done`;
- исходный пример из трёх задач;
- добавление, удаление и переключение готовности с изменением данных;
- проверка названия и часов с ошибками рядом с соответствующими полями;
- сохранение введённых значений при ошибке;
- фильтры «все», «активные», «готовые»;
- расчёт общих часов, выполненных часов и прогресса по всем задачам;
- читаемый интерфейс на ширине 390 px без горизонтального скролла;
- подписи полей и кнопок;
- проверки T1–T5.

Результат работает без сервера, CDN, внешних библиотек и API-ключей.

## Исходный пример

| title | hours | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Каждая задача получает уникальный `id`.

Исходные показатели: всего 8 ч, выполнено 2 ч, прогресс 25%.
После отметки «Практики» готовой: выполнено 6 из 8 ч, прогресс 75%.

## Необязательное улучшение

Сохранение задач в `localStorage` не является условием обязательной приёмки.

Если улучшение реализовано:
- задачи сохраняются между открытиями при доступном хранилище;
- при недоступности хранилища показывается понятное сообщение;
- приложение продолжает работать в памяти;
- описывается ограничение: при открытии через `file://` поведение
  `localStorage` зависит от браузера.

## Вне объёма

Функции сверх перечисленных требований не добавляются.
Отдельная кнопка сброса исходных данных не обязательна.

## Разделение этапов

Этот этап создаёт только спецификацию, дизайн и план работ.
Код реализации подготавливается отдельным запросом.

Запуск OpenSpec CLI, валидатора и браузера не заявляется.
Предложенные проверки и фактически выполненные проверки учитываются отдельно.
