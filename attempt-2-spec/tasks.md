## 2. Предложенные проверки T1–T5

Перед каждым независимым сценарием восстановить исходные данные.
Отдельная кнопка сброса не обязательна.

- [ ] Проверить: выполнено 2 ч.

### T3 — фильтр «активные»

- [ ] Включить фильтр «активные».
- [ ] Проверить: видны только «Практика» и «Повторение».
- [ ] Проверить: исходная коллекция не изменилась.
- [ ] Проверить: всего 8 ч, выполнено 2 ч.
- [ ] Проверить: прогресс остаётся 25%.

### T4 — валидация

Перед каждой независимой проверкой восстановить исходные данные.
При проверке одного поля другое заполнять корректно.

Некорректные значения:
- [ ] Проверить пустое название.
- [ ] Проверить название только из пробелов.
- [ ] Проверить пустые часы.
- [ ] Проверить отрицательные часы.
- [ ] Проверить ноль.
- [ ] Проверить значение ниже 0,5, например 0,25.
- [ ] Проверить значение выше 24, например 24,5.
- [ ] Проверить нарушение шага 0,5, например 0,75.
- [ ] Проверить отклонение нечислового и неконечного значения.
- [ ] В каждом некорректном случае проверить:
      задача не добавлена, ошибка видна рядом с полем,
      все введённые значения сохранены.
- [ ] При ошибках обоих полей проверить сообщения у обоих полей.

Корректные значения:
- [ ] По отдельности проверить успешное добавление с 0,5 ч и 24 ч.
- [ ] Проверить допустимый промежуточный шаг, например 1,5 ч.
- [ ] Проверить, что название «  Задача  » сохраняется как «Задача».
- [ ] Проверить уникальный `id` и `done=false` у новой задачи.
- [ ] Проверить пересчёт показателей после корректного добавления.
